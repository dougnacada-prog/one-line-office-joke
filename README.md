A tiny Node program that prints one office joke: a lunch keeps vanishing from the office fridge, so its owner relabels it "Q3 expense reports" — and nobody has touched it since.

## Run it

```sh
node main.ts
```

That writes the joke, one line of plain text, to `/output/entry.txt`.
